# Scrambled Word Game

A Python-based word guessing game where players unscramble words across three levels of increasing difficulty.

## Features

- 3 levels with 5 words each.
- 2 attempts per word.
- Progress to the next level by guessing correctly.
- Game ends if both attempts are incorrect.

## Requirements

- Python 3.x

## How to Run

```bash
python3 scrambled_word_game.py
```

## How to Play

1. Run the program.
2. Enter the correct word for each scrambled word.
3. Complete all 15 words to win the game.

## Concepts Used

- Dictionaries
- Loops (`for`, `while`)
- Conditional statements
- User input and output
